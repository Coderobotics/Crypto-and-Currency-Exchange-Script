# Crypto & Currency Exchange Script

Exchanger Pro is a ready-to-launch PHP script for running an online currency and cryptocurrency exchange business, sold by Coderobotics. It is built with PHP 8.3, Laravel 13, Livewire 4, Alpine.js and Tailwind CSS 4, and runs on MySQL 8 or MariaDB 10.11+. Customers choose a currency pair, see a live quote, place an exchange order and pay through one of 11 integrated payment gateways: Stripe, PayPal, Paystack, Flutterwave, Razorpay, Mollie, Coinbase Commerce, NOWPayments, Payeer, Perfect Money and a manual bank transfer option. Rates update automatically from CoinMarketCap and Currencylayer. The platform supports fiat and crypto currencies, guest and registered checkout, order tracking, KYC verification, two-factor authentication, Google and Facebook login, support tickets, an affiliate program and notifications by email, SMS and in-app message. Admins get a full panel with statistics, role-based permissions, a CMS, reports, multi-language support with right-to-left layouts and PWA settings. The purchase is a one-time payment that includes the complete source code with no encryption or domain limits, plus one year of free updates and email support.
